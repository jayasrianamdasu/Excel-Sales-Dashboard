# 📊 Excel Sales Performance Dashboard

## About the Project

This project is an automated Sales Performance Dashboard developed in Microsoft Excel using Pivot Tables, Pivot Charts, and VBA.

The dashboard converts raw sales data into meaningful business insights and updates automatically with a single refresh button. It helps analyze sales performance, profit trends, regional performance, category-wise sales, discount impact, and other important business metrics.

The project was created to improve my skills in Excel automation, data visualization, dashboard design, and VBA programming.

---

## Features

- Automated dashboard generation using VBA
- One-click dashboard refresh
- KPI cards for important business metrics
- Sales by Segment analysis
- Monthly Sales Performance tracking
- Sales and Profit Trend analysis
- Sales by Category visualization
- Sales by Region comparison
- Profit vs Discount analysis
- Professional dashboard layout and formatting

## Project Workflow

1. Raw sales data is stored in the **Data** sheet.
2. Pivot Tables summarize the data in the **Pivot** sheet.
3. VBA automatically creates and formats the dashboard.
4. Charts and KPI cards are generated dynamically.
5. Clicking the refresh button updates the entire dashboard.
