# Excel Sales Performance Dashboard

## Overview
A fully automated Excel dashboard built using VBA, Pivot Tables, and Charts.

## Features
- One-click dashboard refresh
- KPI Cards
- Sales Trend Analysis
- Category-wise Sales
- Region-wise Sales
- Profit vs Discount Analysis
- Automated Chart Generation

## Technologies Used
- Microsoft Excel
- VBA
- Pivot Tables
- Pivot Charts
